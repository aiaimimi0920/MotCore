# mot_core：智能核心

本目录为新的智能核心保留开发边界，目前只有职责说明，没有运行时、服务端 API 或已选定技术栈。

## 目标职责

- 会话、上下文和记忆管理。
- 接收用户输入及游戏事件，组织模型调用和决策。
- 插件调用编排与结果处理。
- 在游戏开放能力和用户授权范围内主动交流、提醒和行动。
- 处理用户偏好与本次游玩的行为要求。

部署首先面向云端，但职责不限定只能在云端实现。核心不应依赖桌面 GUI 才能运行，以便游戏直接连接云端伙伴；未来也可以提供本地部署。

## 边界

游戏保留信息开放、行动校验与执行权。用户可以覆盖陪伴与对话偏好，但不能因此获得游戏未开放的权限。

共同经历及用户讲述可以成为伙伴与用户之间的已知知识；外部攻略不能伪装成共同经历。具体记忆结构与存储方式尚未确定，也不属于 G2A 必须统一的实现。

MotGUI 仓库的旧 `core/` 不是本目录的现成实现，本轮没有将其重命名或包装成新的智能核心。
